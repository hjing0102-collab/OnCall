# 内存使用率过高告警处理方案

## 告警信息
- 告警名称: HighMemoryUsage
- 告警级别: 严重
- 触发条件: 内存使用率持续5分钟超过85%

## 排查步骤
1. 获取当前时间（工具: get_current_time）
2. 查询内存指标（工具: query_memory_metrics）
3. 查询错误日志（工具: search_service_logs）

## 常见原因和处理方案

### 原因1: 内存泄漏
特征: 内存使用率持续增长不释放
处理: 重启服务实例，排查代码中的内存泄漏点

### 原因2: 大对象缓存
特征: 缓存占用大量堆内存
处理: 减小缓存大小，设置合理的TTL和淘汰策略

### 原因3: 连接池未释放
特征: 数据库连接数持续增长
处理: 检查连接池配置，确保连接正确关闭

## 紧急措施
1. 重启高内存实例
2. 清理临时缓存
3. 扩容内存资源
