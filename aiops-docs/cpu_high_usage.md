# CPU使用率过高告警处理方案

## 告警信息
- 告警名称: HighCPUUsage
- 告警级别: 严重
- 触发条件: CPU使用率持续5分钟超过80%

## 排查步骤
1. 获取当前时间（工具: get_current_time）
2. 查询CPU指标（工具: query_cpu_metrics）
3. 查询错误日志（工具: search_service_logs）

## 常见原因和处理方案

### 原因1: 死循环或无限递归
特征: 单个进程CPU占用接近100%
处理: 立即重启受影响实例，回滚代码

### 原因2: 流量突增
特征: 多进程CPU均匀升高
处理: 启动自动扩容，启用限流

### 原因3: GC频繁
特征: 内存使用率也高，CPU用于垃圾回收
处理: 调整JVM堆大小，优化GC策略

## 紧急措施
1. 扩容增加实例
2. 启用限流规则
3. 重启异常实例
